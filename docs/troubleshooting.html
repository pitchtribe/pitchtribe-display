Looking after it

Troubleshooting

The usual problems and how to fix them, roughly in the order people run into them. The first thing to try for almost anything: unplug the Pi’s power, wait ten seconds, and plug it back in.

The TV

No picture at all

  • Check the TV is on the right HDMI input — the one the Pi is plugged into.
  • On a Pi 5, use the micro-HDMI socket nearest the power socket (HDMI0).
  • Check the Pi has power: a small light on it should be on. Use the official power supply.
  • Push the memory card fully in. If you’ve just written it, write it again — a card that didn’t finish writing won’t start.
  • Try another HDMI cable or another TV, to rule them out.

Stuck on white text or a black screen

The very first start can take up to five minutes and may restart once — give it time. If it’s still stuck after ten minutes, unplug the power and plug it back in. If that doesn’t help, write the card again; it may have been corrupted.

“This screen has no playlist yet”

PitchTribe is running; it just hasn’t been given anything to show. If you haven’t set up the dashboard yet, open the address shown on the TV and choose a password. If you have, open Screens in the dashboard and pick a playlist for this screen.

The edges are cut off, or there are black bars

Most TVs zoom in slightly by default (“overscan”). In the TV’s picture settings, look for Just Scan, Screen Fit, Full Pixel, 1:1 or Aspect ratio: Original, and choose it for this HDMI input. For black bars around a particular photo, change its Sizing to Fill screen in the dashboard.

The picture is sideways

If the TV is mounted portrait, open Screens in the dashboard and set the screen’s Rotation.

The TV switches itself off

Many TVs have an eco or “auto power off” setting that turns them off after a few hours without the remote being pressed. Switch it off in the TV’s settings — the Pi keeps the picture changing, but some TVs don’t count that.

The Pi restarts on its own, or shows a lightning bolt

That’s nearly always the power supply not providing enough power. Use the official Raspberry Pi supply for your model, plugged straight into the wall rather than an extension with lots of other things on it.

The TV isn’t showing my latest changes

Check the screen shows as Online under Screens and that it’s playing the playlist you changed. Check the item’s Timing allows it to show now — its badge should say Live now. Then use Reload on the Screens page. If the screen is offline, check the Pi’s network connection.

The network

I can’t open pitchtribe.local

  1. Make sure your phone is on the same Wi-Fi network as the Pi. Guest networks and mobile data won’t work. Switch off any VPN.
  2. Type http:// at the start, and use the name you gave the Pi in Imager if you changed it.
  3. Use the numbers instead: the address is shown at the bottom of the TV until the dashboard is set up, and always under Settings → About. Your router’s admin page also lists the Pi under connected devices.

Some Android phones and some routers don’t understand .local addresses at all. The numbered address always works; bookmark it. Ask whoever looks after the router to give the Pi a fixed (“reserved”) address so the number never changes.

The Pi doesn’t join the Wi-Fi

  • The Wi-Fi name and password must be exactly right — they’re case-sensitive. The only way to change them is to write the card again with the correct details in Imager.
  • Networks with a sign-in page (like many guest networks) won’t work. Use the club’s main network.
  • If the router is far away or behind thick walls, use a network cable instead.

Imager didn’t offer to customise the card

Some versions of Raspberry Pi Imager don’t offer the customisation steps (Wi-Fi, hostname, username) for a file chosen with Use custom. You can either use a network cable and skip them, or load the PitchTribe list into Imager, which brings them back:

  1. In Imager, open its settings (App options) and find the content repository setting.
  2. Choose to use a custom repository and enter this address: 
    https://github.com/pitchtribe/pitchtribe-display/releases/latest/download/pitchtribe-imager.json
  3. PitchTribe now appears in Imager’s operating system list. Choose it instead of Use custom, and the customisation steps appear as usual.

The dashboard

I can’t connect with SSH

What the error says tells you what’s wrong:

It saysWhat to do
Connection refusedSSH is off. Switch it on in the dashboard under Settings → Remote access.
Permission deniedWrong username or password. Set a new password for that username in Settings → Remote access. Nothing appears on screen as you type a password — that’s normal.
Could not resolve hostnameYour computer can’t find pitchtribe.local. Use the numbered address from Settings → About instead, e.g. ssh clubadmin@192.168.1.50.
A long pause, then timed outWrong address, or your computer isn’t on the same network as the Pi.

Support access won’t switch on

It saysWhat to do
Support access isn’t available on this PiThe Raspberry Pi Connect client isn’t installed — usually a Pi set up by hand rather than from a PitchTribe card. Install it over SSH with sudo apt install rpi-connect-lite, then reload the dashboard.
This Pi has no login accountThe card was written without a username in Raspberry Pi Imager, so there is no account to run it as. Switch SSH on in Settings → Remote access and choose a username first — that creates one.
Connect didn’t offer a sign-in linkThe Pi couldn’t reach the internet. Check it is online (live scores and weather will be blank too), then try again. Nothing is left switched on when this happens.
It says waiting to be finishedThe link has been given out but nobody has signed in at it yet. Open it on a phone and sign in with the club’s Raspberry Pi ID. If the link has gone stale, tap End support access and switch it on again for a fresh one.
The Pi didn’t open a background sessionRaspberry Pi Connect runs as the club’s own login, and that login’s background session hadn’t started yet. Nothing was switched on. Wait a minute and try again; if it keeps happening, reboot the Pi and try once more.
Still reports this Pi as signed inThe dashboard asked Raspberry Pi Connect to sign out and it didn’t. The Pi keeps trying by itself every few minutes, so this usually clears. To be certain now, remove the device at connect.raspberrypi.com — that works from the club’s side whatever the Pi does.

To take the Pi away from support at any time, sign in to connect.raspberrypi.com with the club’s own Raspberry Pi ID and remove the device. It is the club’s account, so that always works — you don’t need us, and you don’t need the dashboard.

Ending a session and removing the device are not the same thing. Ending a session signs the Pi out on the Pi, which is what stops anyone connecting; the device stays in the club’s list at Raspberry Pi Connect, signed out, until you remove it there.

I’ve forgotten the admin password

Anyone can reset it from a terminal on the Pi (see connecting with SSH — Remote access has to have been switched on, or a username set in Imager, while you could still sign in). Run:

sudo pitchtribe-reset-password

Type the new password twice. Your content is untouched, and everyone signed in to the dashboard is signed out. (If the command isn’t found, update PitchTribe first — it arrived in a later version.)

Live scores or weather are blank

  • Both need the Pi to be online.
  • For scores, check Settings → Sports feeds is switched on with at least one competition ticked. Off-season, there may simply be no matches.
  • For weather, set your ground’s location in Settings → Widgets.

An upload fails

Check the file type (JPG, PNG, GIF, WebP, SVG, MP4 or WebM). Videos from iPhones are sometimes in a format the screen can’t play; export them as MP4 (“Most Compatible” in the iPhone’s camera settings) or convert them first. Very large videos can also take a long time over Wi-Fi — try from a computer on a cable.

Starting again from scratch

If all else fails, write the PitchTribe image to the card again with the beginner’s guide. That wipes the card, including your content — but if you’ve been backing up to a USB stick, plug it in and the first-run screen offers to restore everything, password included.

Backups aren’t working

  • The stick doesn’t appear in Settings → Backups: try another USB port, and give it ten seconds. Sticks formatted NTFS (common on sticks prepared on Windows) aren’t supported — reformat it as exFAT on a computer first.
  • “The backup stick isn’t plugged in”: someone has taken it out. Plug it back in and tap Back up now.
  • “The USB stick is full”: use a bigger stick, or delete other files from it. PitchTribe keeps 30 nights of backups but each photo or video only once, so it’s usually video that fills a stick.
  • No backups offered on a new card: check it’s the right stick, and that the old Pi was backing up to it — Settings → Backups showed a recent “Last: backed up” time.

Still stuck?

Open an issue on GitHub. Say which Pi you have, how you installed PitchTribe, and exactly what the TV shows — a photo of the screen helps a lot. If you’re comfortable with a terminal, the last lines of sudo journalctl -u pitchtribe -u pitchtribe-kiosk -n 100 are very useful too.
