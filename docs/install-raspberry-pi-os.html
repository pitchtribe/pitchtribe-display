Install on Raspberry Pi OS

If your Pi already runs Raspberry Pi OS, one command turns it into a PitchTribe screen. If you’re starting with an empty memory card, the beginner’s guide is quicker — the PitchTribe image has everything below already done.

curl -sSL https://pitchtribe.media/install.sh | sudo bash

Before you start

  • A Raspberry Pi 5 or 4 running Raspberry Pi OS, 64-bit — the current version (Trixie) or the previous one (Bookworm). The Lite version (no desktop) is best.
  • The Pi is connected to the internet. The installer downloads about 400 MB.
  • An HDMI screen attached to the Pi.
  • A way to type commands on the Pi: a keyboard plugged into it, or SSH from another computer.

Use a Pi that does nothing else

PitchTribe takes over the HDMI output and starts the Pi to its own screen instead of a desktop. If your Pi has the desktop version of Raspberry Pi OS, you won’t see the desktop after installing.

Starting with an empty card?

In Raspberry Pi Imager, choose your Pi, then Raspberry Pi OS (other) → Raspberry Pi OS Lite (64-bit), then your card. In the customisation steps, set a hostname (such as bar-tv), a username and password, your Wi-Fi, and switch on SSH. Write the card, put it in the Pi and switch on. Give it a few minutes on first start.

Connecting to the Pi (SSH)

SSH lets you type commands on the Pi from your own computer, over the network. It needs a username and password, and SSH switched on. There are two ways to get them:

  • From the PitchTribe dashboard (PitchTribe 0.2 and later): open Settings → Remote access, switch it on, and choose a username and SSH password. Forgotten the password you set in Imager? Type that username here with a new password.
  • In Raspberry Pi Imager, when you write the card: set a username and password, and switch on SSH, in its customisation steps.
  1. Open a terminal:
    • Windows 10 or 11: right-click the Start button and choose Terminal (or Windows PowerShell).
    • Mac: open Terminal from Applications → Utilities.
    • ChromeOS: switch on Linux in Settings → Developers, then open the Terminal app.
  2. Type the following, using your own username and hostname, and press Enter: 
    ssh yourname@bar-tv.local
  3. The first time, it asks whether you trust this computer. Type yes and press Enter.
  4. Type your password and press Enter. Nothing appears on screen as you type — that’s normal, it’s still working.

When the line starts with something like yourname@bar-tv:~ $, you’re connected. Anything you type now runs on the Pi.

If bar-tv.local isn’t found, use the Pi’s IP address instead (for example ssh yourname@192.168.1.50). Your router’s admin page lists it under connected devices.

Run the installer

Paste this and press Enter (in most terminals, right-click pastes):

curl -sSL https://pitchtribe.media/install.sh | sudo bash

It may ask for your password again. Then it runs on its own for 10–20 minutes, printing what it’s doing. When it finishes it shows the dashboard address:

==> Done!

  Dashboard:  http://bar-tv.local/
              http://192.168.1.50/

  Open it on your phone (same network) to create the admin password.

The TV switches to the PitchTribe screen. Open the address on your phone and carry on from step 7 of the beginner’s guide.

Is it safe to pipe a script into sudo bash?

It’s a fair question: the command runs whatever the website sends as the administrator. You can read the script first — it’s short, and all it does is download PitchTribe’s source code from GitHub and run the installer in it, deploy/install.sh. Or do the same yourself:

sudo apt-get install -y git
git clone https://github.com/pitchtribe/pitchtribe-display pitchtribe
sudo pitchtribe/deploy/install.sh

What it installs

  • Node.js 22, if the Pi doesn’t already have Node 20 or newer.
  • PitchTribe in /opt/pitchtribe, running as the pitchtribe service: the dashboard and the screens’ server, on port 80. Your content and settings go in /var/lib/pitchtribe.
  • The kiosk: Chromium, full screen, in the cage kiosk, as the pitchtribe-kiosk service. It shows this Pi’s screen and restarts itself if anything goes wrong.
  • Avahi, which makes the hostname.local address work.

Nothing is sent anywhere. Running it again later updates PitchTribe and keeps your content — see Updates and backups.

Options

Put options between sudo and bash, like this:

curl -sSL https://pitchtribe.media/install.sh | sudo PITCHTRIBE_PORTAL=1 bash
OptionWhat it does
PITCHTRIBE_PORTAL=1Also set up the guest Wi-Fi portal. The Pi must be on a network cable.
PITCHTRIBE_SERVER=http://clubhouse.localMake this Pi a screen only, showing content from another PitchTribe Pi. See Adding more screens.
PITCHTRIBE_NO_KIOSK=1Install the dashboard and server only, with nothing on the HDMI output — for a Pi tucked away in a cupboard that serves other screens.
PITCHTRIBE_PORT=8080Run the dashboard on a different port (default 80).
PITCHTRIBE_REF=v0.3.0Install a particular release instead of the latest code.
PITCHTRIBE_NO_OS_UPGRADE=1Don't install the waiting Raspberry Pi OS updates while installing — handy on a slow connection when you're in a hurry. The nightly update is set up either way.
